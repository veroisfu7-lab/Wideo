# audio.md — звук, подача текста и темп серии NEURONVISUALS (R1–R7)

Аналитик: «Звук и темп». Все кадры даны при 30 fps: `n = round(t·30)`. Разрешение видео 720×1280.
Измерения лежат в `measurements/audio/`: `R*_frames.csv` (покадровые RMS, пик, L/R-корреляция, баланс, центроид, энергия по полосам), `R*_events.csv` (автодетектор онсетов), `sfx_table_curated.csv` (ручная таблица SFX), `R*_caption_track.csv` (рост пикселей субтитров по кадрам), `R*_spectrogram_onsets.png`, `R*_storyspec_###.png` (раскадровка над спектрограммой, ось X в кадрах), `R*_chroma.png`, `R2R6_sfx_separation.png` + `R2R6_music_vs_sfx.csv`, `R4_voice_check_0-270.png`, `harmonic_peaks_bass.json`, `audio_summary.json`.

Метки достоверности: **[изм]** — прямое измерение; **[оц]** — вывод по спектру и картинке (на слух не проверялось: у аналитика нет слуха, только спектр); **[?]** — не уверен.

## 0. Главное в пяти строках

1. **Диктора нет.** Весь текст выводится на экран: печатается машинкой со скоростью ≈1,45 знака/кадр с проявлением каждой буквы за 3 кадра. Голос появляется только в R4: настоящая реплика «Later» ×4, синхронная с пузырём реплики до ±1 кадра.
2. **Звук = музыкальная подложка с кадра 0 + редкие SFX под физические события** (приземление, падение, удар, капля). Музыка нигде не приглушается под события (дакинга нет). Тишины нет: ниже −50 dBFS звук не опускается ни разу.
3. **R2 и R6 используют один и тот же музыкальный трек, совпадающий до сэмпла с кадра 0** (корреляция окон 0,76–0,91 при нулевом сдвиге). Значит, музыку берут из библиотеки и кладут с начала ролика, а не генерируют под каждый ролик.
4. **Фирменный SFX серии — низкий «бум» с падением высоты тона** (≈250→60–70 Гц за 8–10 кадров) на каждом падении или приземлении (R1, R6, R7; в R3 его заменяют короткие суб-удары).
5. **Финал:** картинка уходит в чёрное за 10–14 кадров, а звук в 5 из 7 роликов **обрывается на полной громкости**. Петли нет.

## 2. Музыка

### 2.1 Что за музыка (по спектру) [оц]
- **Пэд или дрон со множеством устойчивых гармоник** в диапазоне 200 Гц – 3 кГц (горизонтальные линии через весь ролик) — R1, R2/R6, R3, R5. Ударных почти нет: перкуссия на 5–11 dB тише гармонической части (HPSS: perc/harm = −5…−11 dB [изм]).
- **Суб-бас 40–100 Гц** есть везде. В R1, R6 и R7 он с **глиссандо вниз** («808-слайд» или «бум»). Именно эти глайды совпадают с падениями и приземлениями, так что это скорее SFX, вписанные в музыку.
- **R4 — фортепиано**: дискретные выдержанные ноты с затуханием и шаговым басом. Сентиментальная баллада, единственный «тёплый» трек.
- **R7 — ритмичный трек на 120 BPM** с киком на G1 (49 Гц) и светлой гармонией G-мажор. Единственный «весёлый» трек: комедийный сюжет про блины.
- Тональности: G#m (R1, r = 0.87), Cm/Fm (R2/R6, r = 0.62/0.68), Em (R3), B♭/Gm (R4, r = 0.71), D с G# — лидийская окраска (R5), G (R7). Общее правило: **минорные или подвешенные (sus) медленные пэды для драмы, мажор и бит для комедии**.

### 2.2 Совпадение треков [изм]
- R2 и R6 совпадают до сэмпла: окна по 2 с, нормированная кросс-корреляция 0,60 / 0,78 / 0,79 / 0,81 / 0,91 / 0,76 / 0,76 / 0,89 / 0,91 / 0,89 для секунд 0–9 при сдвиге 0. Оконная хрома-корреляция 0,83–1,00. Музыка в обоих роликах начинается с кадра 0 и с начала трека. Хвост R6 (после 11,7 с) — продолжение того же трека.
- R7 частично похож на R2/R6 по хроме (0,48 при сдвиге ≈270 кадров), но волнового совпадения нет: другой трек того же лада.
- Остальные пары не совпадают (максимум NCC < 0,3).
- **Вывод для исполнителя:** один библиотечный трек можно ставить в несколько роликов, всегда с 0:00 трека на кадр 0 видео, без подгонки по фазе.

### 2.3 Структура во времени [изм]
- **Начало:** у 5 роликов музыка звучит с кадра 0 на рабочем уровне. Фейд-ина нет: R2/R6 добирают 3–4 dB за первые 3–8 кадров. У R3 и R5 есть **тихое интро ≈1 с** (−28…−30 dBFS) и вход «полной» музыки на кадрах 27 и 31 (+15…+17 dB). Визуальной склейки там нет.
- **Середина:** громкость ровная, LRA до 4,6 LU. Заметных крещендо нет. Музыку меняют только смены аккордов (раз в 1,5–3 с).
- **Конец:** см. §6. Хвоста реверберации нет; звук обрывается вместе с последним кадром. Аудиопоток длиннее видео на ~0,11 с (это AAC-паддинг).

### 2.4 Рецепт музыки для исполнителя
- Драма или мораль: медленный минорный или sus-пэд, без ударных, суб-бас с редкими глайдами вниз; аккорд держится 1,5–3 с. Уровень после нормализации ≈ −17 dBFS RMS.
- Ностальгия про семью: соло-фортепиано, медленный нисходящий бас, мажорная тональность с переходами в относительный минор.
- Комедия: 120 BPM, кик на восьмые, мажор, мультяшные свистки.
- Трек ставится с начала (0:00) на кадр 0. Дакинга нет. Финальную нормализацию делать в −14 LUFS (платформа или экспорт), true peak ≤ −0,5 dBFS.

## 4. Уровни, дакинг, тишина, стерео

### 4.1 Музыка против SFX [изм]
- Точное разделение получилось для R2 и R6 (общая музыка вычтена спектрально, `R2R6_sfx_separation.png`): **слой SFX в среднем на 15 dB тише музыки**, пики от −5 до +10 dB. Примеры для R6: кадр 18 → +5 dB, 186 → +10, 209 → +5, 296 → +4 относительно музыки.
- Для остальных роликов скачок покадрового RMS на событии относительно медианы 8 предыдущих кадров: **обычно +2…+9 dB**, максимум +13 dB (R7, удар по голове, кадр 312). В своей полосе удар выше на 15–35 dB (суб-бумы).
- Голос R4 выше подложки на +3…+8 dB в момент слога.
- Тихие SFX (бипы, чирпы, колокольчики) лежат на −5…−10 dB под подложкой.

### 4.2 Дакинг [изм]
Нет. Оконная оценка усиления музыки R6 относительно R2 по 0,5 с (полоса 150–900 Гц) после кадра 30 стабильна: 0…−2 dB при корреляции 0,83–0,99. Провалы совпадают с SFX, а не с автоматизацией. Под голосом R4 музыка тоже не опускается: RMS подложки вокруг реплик не падает.

### 4.3 Тишина [изм]
Порог −50 dBFS не пересекается нигде, кроме самого последнего аудиокадра R3. Самые тихие места — тихие интро R3 (−35 dBFS на кадре 18) и R5 (−32 dBFS на кадре 3), а также хвост R7 (−35 dBFS). **Пауз-тишин для драматургии серия не использует.**

### 4.4 Стерео [изм]

## 7. Что удивило

3. **R5 почти полностью декоррелирован по стерео** (corr 0,01). Остальные ролики почти моно.
4. **Аудио обрывается на полной громкости, хотя картинка уходит в чёрное.** Кроссфейда звука нет в 5 из 7 роликов.
5. ASR в R7 принял слайд-свисток за «What? No!», а в R4 сместил метки на ~0,5–0,9 с раньше. Метки whisper для такого контента непригодны.
