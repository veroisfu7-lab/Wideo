# NEURONVISUALS-style: притча с человечками — от идеи до готового mp4

Скилл делает ролики только в одном стиле — том, что уже разобран и отработан на «Пути под ногами», «Песочных часах» и «Ведре и трубе» (30 с — эталон темпа, сэр: «кайф»). Все числа стиля лежат в `references/`, разбирать стиль заново не нужно и новые стили скилл не делает. Процесс: идея → одобрение → сборка кодом → самопроверка → независимый ревьюер → сдача.

## Жёсткие правила (до любых действий)
- Ничего не покупать, не вводить данные карт, нигде не регистрироваться.
- Платные генерации (Higgsfield/Seedance, APIMart, Flow) — только после слова сэра «запускай» и с названной заранее ценой в гривнах.
- Скачивать и сохранять только кодом (curl/Python/ffmpeg), без окон «Сохранить как». Капчи и Cloudflare не обходить.
- Рендерить кусками и черновиками (`--scale=0.25`, `--frames`). Временные файлы держать внутри проекта (`checks/`, `out/`) и чистить при сдаче.
- Файлы сэра и чужие проекты не удалять и не менять. Новый ролик — в новой папке или новой композиции.
- Права на музыкальный трек остаются на сэре. Писать это в каждом отчёте.
- Что оценено, а не измерено (шрифт, параметры свечения, названия звуков по спектру), так и подписывать: «оценка».
- Вотермарк рефа (NEURONVISUALS) в новый ролик не ставить.
- Обращение «сэр». Идею сначала описать и дождаться «делаем»; сложный ролик сначала пилотом.

## Порядок работы

### Шаг 1. Входные данные
Выясни из запроса: тема или идея, формат (по умолчанию 1080×1920, 30 fps, 11–16 с или длинная версия 25–30 с, если сэр просит «плавнее» — тогда по рецепту ENGINE §4a, текст на русском, шрифт Tektur), музыка (если сэр назвал трек — его, иначе подобрать в TikTok).
Стиль всегда берётся из готового `STYLE_RULES.md`. Если сэр присылает рефы другого стиля — сказать, что этот скилл делает только наш стиль.

### Шаг 2. Идея → одобрение
Прочитай `story.md` (формула и шаблон) и раздел «Идея и сценарий» в `PITFALLS.md`. Предложения сэр оценивает строго:
- 10 идей = 10 **разных форматов**, а не одна схема в разных декорациях;
- не каждый раз пара «хороший/плохой» и не «отъезд на толпу»;
- без перегруженных «нейрослопных» историй;
- человечки в центре;
- метафора понятна за 1–2 секунды.

Выбранную идею опиши таблицей «секунды → что происходит», подписи (две строки ≤ 32 знаков), звуки, что тестируем по анимации. Жди «делаем».

### Шаг 3. Способ сборки
По умолчанию **Remotion + Three.js, всё кодом**: бесплатно, точно по числам гайда, без артефактов нейросети.
- Blender через MCP — только если не хватает отражений или свечения.
- Нейросеть (Flow, Seedance через Higgsfield) — только если игру персонажей не собрать кодом, и только после «запускай» с ценой.

### Шаг 4. Пилот — когда нужен
Нужен, если в сцене есть механика, которой нет в примерах шаблона (вода, ткань, толпа больше 5 человек, транспорт, огонь крупным планом и т. п.). Тогда сначала 5–10 с, кадры «реф | мой» рядом, дальше — после «ок» сэра. Если сцена собирается из того, что уже есть в `src/path`, `src/hourglass` и `src/well` (ходьба, подъём, прыжок/вис, разворот, жесты, частицы, тела вращения, луч, зеркальный пол, вода и струи, ведро, лопата, укладка предметов, кран, смех с «ХА»), пилот не нужен — сразу полный ролик черновиками.

### Шаг 5. Сборка (по `references/ENGINE.md`)
1. Скопируй `assets/template/` в новую папку проекта (латиница), `npm install`, проверь рендер примера.
2. Скопируй ближайший пример целиком: `cp -r src/hourglass src/<имя>` (или `src/path`; для двух героев и длинного ролика — `src/well`, там постановка в `plan.ts`, звук `tools/sfx_well.py` + `tools/well_events.sh`) — импорты `../anim`, `../Stickman`, `../Reel` останутся рабочими. Правь `timeline.json` (все тайминги), `Scene.tsx` (сцена), `Main.tsx` (имя компонента) и добавь строку в `Root.tsx`. Звук: `cp tools/sfx_hg.py tools/sfx_<имя>.py` и поменяй в нём путь к timeline.json и имена выходных файлов.
3. Правила стиля, которые держишь всё время:
   - персонажи плоские (unlit, обводка 0.1·D, щель у шеи), сцена объёмная;
   - один план без склеек, затемнение в чёрное 10–17 кадров;
   - цвет героя показывает его состояние (серый — «спит», белый со свечением — «живёт»);
   - один цветной акцент на ролик;
   - подпись: 1-я строка с кадра 0, 2-я машинкой через 0–1 кадр после удара поворота;
   - камера медленная, пик ≤ ~15 px/кадр;
   - поворот на 45–66 % длительности (в длинной 30-секундной версии — ≈75 %, после поворота ≈7 с почти в обычном темпе);
   - глянцевый пол с отражениями по умолчанию, если люди стоят на земле (ENGINE §4b);
   - темп спокойный: шаг ≈20 кадров, у каждого героя своя карта времени, физика воды и падения — в реальном времени.
4. Черновик после каждого крупного изменения: `npx remotion render src/index.ts <Id> out/draft.mp4 --scale=0.25`, затем `scripts/contact_sheet.py out/draft.mp4 ...`. Ищи баги из PITFALLS §3–5 и пустые кадры (`selfcheck.py` → `dark_frames_outside_fade`).
5. Звук:
   - `tools/sfx_<имя>.py` (на основе `sfx_hg.py`, на каждое движение — свой звук);
   - музыка: `scripts/fetch_tiktok_sound.py`, потом `scripts/music_onsets.py <трек> <кадр поворота>` для выбора OFF;
   - сведение: `scripts/mix.sh` (статическая нормализация; `DUR` = total/30);
   - уровни: `scripts/levels.py` (последний аргумент — та же длительность).
6. Финал: рендер 1080×1920 `--crf=16` и мукс AAC 192k.

### Шаг 6. Проверки (`references/REVIEW_CHECKLIST.md`)
1. Раздел A (`scripts/selfcheck.py`, `levels.py`) и раздел B (визуальные баги) — сам.
2. Раздел C — **независимый ревьюер**: отдельный фоновый агент получает только рендер, рефы (серия NEURONVISUALS: `D:\Клод мотивация\*.mp4` + фото), `STYLE_RULES.md`, одобренный бриф и стемы. Кода и твоих объяснений не получает. Смотрит три прохода, ставит оценки 1–10, порог 9.
3. Его находки подтверди по кадрам, исправь, перепроверь всё (регрессии). Повторная проверка — тому же ревьюеру через SendMessage.

До 4 кругов. Если не сходится — честно напиши, какая проверка, какие числа, какие варианты.

### Шаг 7. Сдача
- Файл в корень рабочей папки с русским именем («<Название>.mp4»); отправить сэру через SendUserFile, если инструмент доступен, иначе дать путь ссылкой.
- Отчёт:
  - что в ролике (биты, подписи, звук, музыка);
  - что нашёл ревьюер и что исправлено;
  - что осталось хуже рефа или некритично;
  - что не слушал на слух (баланс по замерам);
  - права на трек — на сэре.
- Временное (`checks/`, черновые `out/*_v*.mp4`, `_pre.wav`) убрать или перечислить сэру, что можно удалить.
- Если просят подпись для Instagram — подпись и хэштеги одним блоком.

## Быстрая шпаргалка команд
```bash
# проект
cp -r "<skill>/assets/template" "<work>/<name>" && cd "<work>/<name>" && npm install
cp -r src/hourglass src/<name> && cp tools/sfx_hg.py tools/sfx_<name>.py   # + строка в src/Root.tsx
npx remotion render src/index.ts <Id> out/draft.mp4 --scale=0.25 --log=error
python -I "<skill>/scripts/contact_sheet.py" out/draft.mp4 checks/sheet.jpg --step 6 --cols 10 --width 160
# звук
python -I tools/sfx_<name>.py
python -I "<skill>/scripts/fetch_tiktok_sound.py" "<tiktok video url>" public/music
python -I "<skill>/scripts/music_onsets.py" public/music/<track>.mp3 <кадр_поворота>
TRACK=public/music/<track>.mp3 OFF=<сек> MUS=-15 SFX=-4 DUR=<total/30> STEM=public/sfx_<name>.wav OUT=out/audio.wav sh "<skill>/scripts/mix.sh"
python -I "<skill>/scripts/levels.py" -4 -15 public/music/<track>.mp3 <OFF> public/sfx_<name>.wav checks/sfx_<name>_events.csv <total/30>
# финал
npx remotion render src/index.ts <Id> out/video_silent.mp4 --codec=h264 --crf=16 --log=error
ffmpeg -v error -y -i out/video_silent.mp4 -i out/audio.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest out/<name>_v1.mp4
python -I "<skill>/scripts/selfcheck.py" out/<name>_v1.mp4 --timeline src/<name>/timeline.json --hero-frame <кадр>
```
`<skill>` = папка этого скилла.
